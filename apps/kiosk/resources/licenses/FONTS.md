# Bundled font notices

Grace Booth bundles the following font families through the local `@fontsource` packages. No font is requested from the network at runtime.

- Inter, copyright The Inter Project Authors.
- Montserrat, copyright The Montserrat Project Authors.
- JetBrains Mono, copyright JetBrains s.r.o.

All three families are distributed under the SIL Open Font License 1.1 in `OFL-1.1.txt`. Font package versions are pinned in `apps/kiosk/package.json`.
