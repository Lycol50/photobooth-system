# Bundled font notices

The Grace Booth public page bundles Inter, Montserrat, and JetBrains Mono through pinned local `@fontsource` packages. It never requests fonts from a runtime network service.

- Inter, copyright The Inter Project Authors.
- Montserrat, copyright The Montserrat Project Authors.
- JetBrains Mono, copyright JetBrains s.r.o.

All three families are distributed under the SIL Open Font License 1.1 in `OFL-1.1.txt`.
